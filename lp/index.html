本ワークスペースに含まれるシステム

住民名簿管理から、資料配布、予約管理、部門別出欠、安否確認までを一貫して扱える構成です。

01

プロフィール登録

LINEユーザーIDを利用し、住民の連絡先・希望方法・所属情報を登録し、更新まで一括管理できます。

02

お知らせ配信

月次お知らせや案内の配信ページと連動し、必要な情報を自動的に届ける仕組みを備えています。

03

出欠管理

参加可否の回答を記録し、各イベントの参加者状況をスプレッドシート上で把握できます。

04

会場予約

施設や部屋の利用予約を管理し、申込・承認・通知の流れをLINEと連携させて運用できます。

05

安否確認

状況を段階的に回答させ、未登録ユーザーは自動で登録へ誘導し、回答とログを残します。

06

運用基盤

共通のLIFF設定、共通GAS構成、スプレッドシート連携で、各機能を統一運用基盤として扱えます。

運用の流れ

LINEでの利用から、GAS処理、Spreadsheet保存までを一つのループとして閉じています。

1

ユーザーがLINE内でLIFF画面を開く

各アプリに対応するLIFFページが起動し、ユーザー情報とLINE IDを取得します。

2

LIFF画面がGAS Web AppへAPIリクエスト

リクエストには action、sid、line_id などが含まれ、バックエンドが必要な処理を決定します。

3

GASがデータの解決と更新を担当

名簿参照、回答保存、ログ追加、通知判断などをGoogle Apps Scriptがまとめて実行します。

4

Spreadsheetに結果を残す

名簿・回答・アクセス履歴・予約などをシート単位で管理し、後続の分析や運用に使えます。

構成図

本システムは、ユーザー体験・処理基盤・データ保管・管理運用を分離し、直感的に拡張できる設計です。

層 役割 代表技術
UI 利用者が操作するページ LIFF / HTML / JavaScript

データ 名簿・回答・ログの保存 Google Spreadsheet
運用 URL発行・メニュー管理・確認 Spreadsheet-bound GAS
